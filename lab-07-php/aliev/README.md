## Ответы на вопросы самопроверки

1. `e()` нужен даже для «своих» данных, потому что данные могут измениться, прийти из формы или базы и содержать `<`, `>`, `"`. Экранирование предотвращает XSS.
2. `require` при ошибке подключения останавливает выполнение, `include` — только предупреждает. Для шапки, подвала и функций нужен `require`, чтобы страница не собралась в неполном виде.
3. `<?=` — короткая запись `<?php echo ...; ?>`. Она выводит результат выражения, например `<?= e($post['title']) ?>`.
