# Лабораторная работа №10 — Таблицы, связи, ключи и ограничения MySQL

**Тема:** нормализованная структура базы данных.
**Цель:** спроектировать и создать полную схему блога: `users`, `categories`, `posts`, `comments` с ключами, связями, ограничениями и индексами.

## Краткая теория
- **PK (PRIMARY KEY)** — уникальный идентификатор строки (`id`, автоинкремент).
- **FK (FOREIGN KEY)** — связь таблиц: `post.user_id → users.id`. Правила при удалении: `ON DELETE CASCADE` (удалить вместе родителя) / `RESTRICT` (запретить, пока есть дети).
- **Ограничения:** `NOT NULL`, `UNIQUE`, `DEFAULT`, `CHECK`, типы `ENUM`.
- **Индексы** ускоряют выборку по столбцам (WHERE/ORDER/JOIN). Полнотекстовый индекс (`FULLTEXT`) — для поиска.
- **Референсная схема уже есть** в `database/schema.sql` — ваша задача понять её и воспроизвести «своими руками», добавив свой вариант (например, поле-теги или расширение).
