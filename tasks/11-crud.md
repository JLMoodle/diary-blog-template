# Лабораторная работа №11 — Реализация CRUD

**Тема:** создание, чтение, изменение, удаление записей.
**Цель:** получить полнофункциональную админку блога: добавлять, просматривать, редактировать и удалять записи через форму и SQL.

## Краткая теория
- **CRUD** = Create → **INSERT**, Read → **SELECT**, Update → **UPDATE**, Delete → **DELETE**.
- Чтение одной записи: `SELECT * FROM posts WHERE id = ?` + `fetch()`.
- Форма редактирования **предзаполняется** данными из БД (value из выбранной записи).
- Удаление — кнопка-форма (POST) с подтверждением `onclick="return confirm(...)"`, а не «ссылка-delete» (опасность — лаба 14).
- Идентификация записи: `$_GET['id']` для страницы чтения/редактирования; в обработчиках POST — скрытое поле `<input type="hidden" name="id">`.
- Все SQL — параметризованные (prepared statements).

## Ход работы
1. **Create (`posts/add.php`)**: форма POST → после валидации `INSERT INTO posts (user_id, category_id, title, content, status) VALUES (?,?,?,?,?)`. Выбор категории — из таблицы `categories`. Редирект на страницу созданной записи или на главную.
2. **Read**: 
   - список (`posts/index.php`) — уже есть; 
   - детальная страница записи `posts/view.php?id=HE` — заголовок, дата, автор, категория, полный текст и комментарии к ней.
3. **Update (`posts/edit.php`)**: GET `?id=` → найти запись, вывести форму с заполненными значениями; POST — обновление `UPDATE posts SET title=?, category_id=?, content=?, status=? WHERE id=?`, снова валидация, редирект на `view.php`.
4. **Delete (`posts/delete.php`)**: форма с кнопкой «Удалить» на странице записи; POST `id` → `DELETE FROM posts WHERE id = ?` → редирект на список. Комментарии удалятся сами (CASCADE, лаба 10).
5. Свяжите всё интерфейсом: на карточке записи — ссылки «Просмотр / Редактировать / Удалить».
6. Убедитесь, что статус записи управляем: опубликовать / снять с публикации (поле `status`).

## Самопроверка

- Почему UPDATE без `WHERE id = ?` обновит все записи таблицы?
- Зачем после INSERT/UPDATE/DELETE делать редирект?
- Почему страница `view.php` должна проверить, что запись существует (что будет, если `?id=999`)?

## Критерий «зачтено»
- Полный CRUD для записей: создание, просмотр списка + детальной записи, редактирование с предзаполнением, удаление с подтверждением.
- Все операции — параметризованными SQL-запросами.
- Интерфейс-навигация между списком, просмотром, редактированием, удалением.
- После операций — корректные редиректы (нет повторного INSERT при обновлении страницы).
