# Лабораторная работа №2 — HTML. Структура клиентского приложения

**Тема:** семантическая разметка страниц блога.
**Цель:** создать каркас сайта на HTML5, используя осмысленные (семантические) теги.

## Краткая теория
- **Семантика** — теги, несущие смысл, а не только внешний вид: `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<aside>`, `<footer>`.
- `article` — самостоятельный блок (запись блога); `section` — раздел страницы; `aside` — боковая колонка; `nav` — навигация.
- В `<head>`: кодировка `<meta charset="UTF-8">`, viewport для мобильных, `<title>`.
- Валидность HTML проверяется на validator.w3.org.

## Ход работы
1. Доработайте `index.html` из шаблона — он должен содержать:
   - `<header>` с заголовком блога и меню `<nav>` (Главная, О блоге);
   - `<main>` с `<section>` «Последние записи» и карточками записей на базе `<article>`: заголовок, дата (`<time>`), краткий текст;
   - `<aside>` «Категории» со ссылками на категории;
   - `<footer>` с копирайтом.
2. Создайте (дополните) вторую страницу `about.html` «О блоге» с автором и целью блога.
3. Свяжите страницы между собой ссылками в меню.
4. Добавьте на главную **2–3 собственные** записи (реальные темы вашего дневника).
5. Проверьте HTML на валидность.

## Самопроверка
- Почему нельзя всё оборачивать в `<div>`?
- Зачем тегу `article` отдельные `<header>` / `<footer>`?
- Что изменится для пользователя, если убрать семантические теги?
- Зачем нужен `<meta name="viewport">`?

## Критерий «зачтено»
- Обе страницы (`index.html`, `about.html`) валидны и связаны между собой.
- Использованы семантические теги из списка выше.
- На главной есть не менее 2 собственных записей-`article`.
