# Лабораторная работа №5 — JavaScript DOM, формы и события

**Тема:** динамическое формирование интерфейса и валидация данных.
**Цель:** строить интерфейс через DOM, добавить форму создания записи с проверкой данных и сохранять её в localStorage.

## Краткая теория
- **DOM** — дерево элементов страницы. Поиск: `querySelector`, `querySelectorAll`, `getElementById`. Создание: `document.createElement`, `append`, `textContent`, `insertAdjacentHTML`.
- **События:** `addEventListener('click' | 'submit' | 'input' | 'keyup', handler)`.
- **Валидация** — проверка данных: непустое поле, минимальная длина, корректный формат.
- **localStorage** — хранилище браузера: `localStorage.setItem(key, JSON.stringify(...))`, `getItem`, `removeItem`. Работает между перезагрузками страницы.

## Ход работы
1. Перепишите вывод записей с `innerHTML` на создание элементов через DOM (`createElement`) — используйте `textContent` для контента (безопасно от «ломания» разметки).
2. Создайте форму «Новая запись» в блоке `<section>` (или на отдельной странице): поля «Заголовок», «Категория» (select), «Текст». Показывайте/скрывайте её кнопкой.
3. Подпишитесь на `submit`: перехватите событие (`.preventDefault()`), возьмите значения полей, проверьте валидность:
   - заголовок не короче 3 символов;
   - текст не короче 20 символов;
   - категория выбрана.
4. При ошибках показывайте сообщения рядом с полями (класс `error` и стили в CSS). При успехе — добавляйте запись в начало списка DOM и сохраняйте в localStorage (массив добавленных записей).
5. При загрузке страницы объединяйте записи: массив `posts` + добавленные из localStorage. Так пользовательские записи не «пропадают».
6. Добавьте кнопку «Сбросить свои записи» (очистка localStorage).

## Критерий «зачтено»
- Список записей строится средствами DOM.
- Форма валидируется, ошибки показаны пользователю, невалидная запись не добавляется.
- Записи, добавленные в форме, сохраняются в localStorage и восстанавливаются после перезагрузки.
