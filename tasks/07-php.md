# Лабораторная работа №7 — PHP. Создание серверной части приложения

**Тема:** переход от статики к серверному рендерингу.
**Цель:** превратить блог в приложение на PHP: общие части сайта вынести в `includes/`, записи — в массив на стороне сервера.

## Краткая теория
- **PHP** выполняется на сервере: результат его работы — HTML, который видит браузер.
- PHP-вставки: `<?php ... ?>` и сокращённая форма вывода `<?= $var ?>`.
- Массивы и циклы: `foreach ($posts as $post) { ?> ... <?php } `.
- **`include` / `require`** подключают общие части (шапка, подвал, функции). `require` обрывает работу при ошибке.
- Переменные задаются до подключения шапки: `$pageTitle = 'Главная'; require 'includes/header.php';`.
- Запуск: встроенный сервер `php -S localhost:8000`.

## Ход работы
1. Переименуйте `index.html` в `index.php` (впоследствии главная всегда будет `.php`).
2. Подключите `includes/header.php` и `includes/footer.php`:
   ```php
   $pageTitle = 'Главная'; 
   require __DIR__ . '/includes/header.php';
   // ... контент ...
   require __DIR__ . '/includes/footer.php';
   ```
   Доработайте шапку: заголовок — ссылка на главную, в `<nav>` пункты «Главная», «О блоге».
3. Перенесите свои записи из `data/posts.json` в PHP-массив `$posts` (положите его в `includes/functions.php` или в отдельную файл-данных, вернув функцией `getPosts()`).
4. Выведите записи циклом, используя семантическую разметку из лабы 2.
5. Подключите `includes/functions.php` на странице и используйте функцию `e($post['title'])` для вывода заголовков и текста (см. лабу 14 — защита от XSS).
6. Проверьте работу через `php -S localhost:8000`.

## Критерий «зачтено»
- Главная работает как `index.php`, данные — в PHP-массиве, вывод циклом.
- Шапка и подвал вынесены в `includes/` и подключаются.
- Вывод всех пользовательских значений — через функцию экранирования `e()`.
