# Лабораторная работа №3 — CSS. Оформление и адаптация интерфейса

**Тема:** стилизация блога и адаптивный дизайн.
**Цель:** придать блогу аккуратный вид, задать собственную цветовую тему и сделать страницы удобными на телефоне и на десктопе.

## Краткая теория
- **CSS-переменные:** `:root { --color-accent: #9c27b0; }` и использование `color: var(--color-accent)`. Один цвет — одно место для изменения темы.
- **Ресет:** `* { margin: 0; padding: 0; box-sizing: border-box; }` убирает дефолтные отступы.
- **Раскладка:** Flexbox (`display: flex`) для панелей/карточек и **Grid** (`display: grid; grid-template-columns`) для раскладки страницы «контент + сайдбар».
- **Адаптивность:** медиазапросы `@media (max-width: 768px) { ... }` меняют раскладку под ширину экрана.

## Ход работы
1. Подключите `css/style.css` в обе страницы.
2. Настройте переменные под свою тему (фон, текст, акцентный цвет, радиус скруглений, отступы).
3. Постройте раскладку: шапка, «контент + сайдбар», подвал. Используйте Grid или Flexbox.
4. Оформите карточки записей (фон, тень, радиус), меню, кнопки.
5. Добавьте медиазапросы:
   - до 768px — сайдбар уходит под контент;
   - до 480px — меню становится «столбиком», шрифты меньше.
6. Проверьте вёрстку на разных ширинах (инструменты разработчика браузера → режим устройства).
