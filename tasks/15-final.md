## Ход работы

### 1. Функциональный тест-чеклист
Пройдите по каждому пункту вручную и отметьте результат:
- [ ] Главная показывает записи из БД (последние — первыми)
- [ ] Открывается детальная страница записи (заголовок, дата, автор, категория, текст)
- [ ] Поиск по заголовку/тексту находит и не находит правильно
- [ ] Фильтр по категории работает; сочетание поиска и фильтра «живёт» в URL
- [ ] Пагинация переключает страницы, при этом фильтры сохраняются
- [ ] Добавление записи: валидация ошибок → успех → запись на главной
- [ ] Редактирование: форма предзаполнена, изменения сохраняются
- [ ] Удаление: подтверждение, запись и её комментарии удалены

- [ ] CSRF: подделанный запрос без токена отклоняется
- [ ] XSS: ввод `<script>alert(1)</script>` выводится как ТЕКСТ, не исполняется
- [ ] Адаптивность: страницы выглядят корректно на 375px и 1280px
- [ ] Каждая форма валидируется и на сервере (важно), и на клиенте (удобно)
