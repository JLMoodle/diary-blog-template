# Лабораторная работа №6 — Fetch API. Получение данных с сервера

**Тема:** асинхронная загрузка записей блога.
**Цель:** вынести данные записей в файл `data/posts.json` и загружать их через `fetch()` с обработкой состояний загрузки и ошибок.

## Краткая теория
- **fetch(url)** возвращает промис; `await` ждёт результат. Работать нужно в `async`-функции.
- Ответ: `await response.json()` — тело как JavaScript-объект.
- Статусы: `response.ok` — успех. Ошибку сети/файла нужно ловить (`try/catch`) и показывать пользователю.
- «Имитация сервера»: файл `.json` отдаётся локальным сервером (см. ниже), а лаба 7 заменит его на реальный PHP + лаба 9 на БД.
- **Важно:** при открытии `index.html` двойным кликом `fetch` может не работать из-за ограничений браузера (CORS/file://). Нужен локальный сервер.

## Ход работы
1. Перенесите свои 5+ записей из `js/main.js` в файл `data/posts.json` (уберите массив, оставьте вызов загрузки).
2. В `js/main.js` напишите `async function loadPosts()`:
   - `const res = await fetch('data/posts.json');`
   - убедитесь, что `res.ok` (иначе выбросьте ошибку);
   - `const posts = await res.json();`
   - вызовите `renderPosts(posts)`.
3. Добавьте состояние **загрузки** (перед fetch показать «Загрузка записей…») и **ошибки** (показать в `<section>` сообщение, не в консоль только).
4. Объедините с лабой 5: после загрузки `posts` из файла добавьте записи из localStorage (функция из лабы 5).
5. Запускайте проект через локальный сервер:
   ```bash
   php -S localhost:8000      # или python3 -m http.server 8000
   ```
   и открывайте `http://localhost:8000`.
6. Проверьте, что записей больше 5 (из файла + ваши из формы).

## Критерий «зачтено»
- Записи загружаются из `data/posts.json` через `fetch`/`async-await`.
- Присутствуют состояния «загрузка» и «ошибка» с сообщениями пользователю.
- Проект запускается на локальном сервере, записи из формы (localStorage) не теряются.
