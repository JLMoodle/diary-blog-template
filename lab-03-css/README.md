# Лабораторная работа №3 — CSS. Оформление и адаптация интерфейса

## Как работать в этой лабе (общий репозиторий группы)

В этой папке `lab-03-css/` вы создаёте свою подпапку по фамилии и ведёте код только в ней.

1. Перед началом работы забрать чужие правки: `git pull --rebase`.
2. Создать свою подпапку: `mkdir lab-03-css/<Фамилия>` (латиницей, например `kimsan`).
3. Скопировать скелет лабы **целой папкой** в свою подпапку, чтобы не сломались
   относительные пути (`css/`, `js/`, `data/`, `includes/`).
4. Правите только своё; чужие подпапки и скелеты не трогайте.
5. Сдача лабы — см. раздел «Как отправить» в конце этого файла.


## Цель

Придать блогу аккуратный внешний вид: собственная цветовая тема через CSS-переменные,
раскладка Flexbox/Grid, карточки записей и **адаптивность** (страница корректно выглядит
и на телефоне, и на десктопе).

## Что нужно реализовать (чек-лист)

- [ ] Подключён `css/style.css` в `index.html`.
- [ ] Цветовая тема задана CSS-переменными (`:root`), не хардкодом.
- [ ] Раскладка страницы «контент + сайдбар» через Grid или Flexbox.
- [ ] Оформлены: шапка, меню, карточки записей, сайдбар, подвал, кнопки/ссылки.
- [ ] Медиазапросы: до 768 px сайдбар уходит под контент; до 480 px меню становится вертикальным.
- [ ] Страница корректно «переживает» ширины 375 px и 1280 px.

## Объяснение (мини-теория + документация)

- **CSS-переменные** (custom properties): объявляются в `:root`, используются через `var()`:
  меняете цвет в одном месте — меняется тема везде. https://developer.mozilla.org/en-US/docs/Web/CSS/Using_CSS_custom_properties
- **Ресет** `* { margin: 0; padding: 0; box-sizing: border-box; }` убирает непредсказуемые
  отступы браузера по умолчанию. https://developer.mozilla.org/en-US/docs/Web/CSS/CSS_box_model
- **Flexbox** — одномерная раскладка (строка/столбец): для меню и карточек в ряд.
  https://developer.mozilla.org/en-US/docs/Web/CSS/CSS_flexible_box_layout
- **Grid** — двухмерная сетка: «контент | сайдбар». https://developer.mozilla.org/en-US/docs/Web/CSS/CSS_grid_layout
- **Медиазапросы** `@media (max-width: 768px) { ... }` включают правила при узком экране.
  https://developer.mozilla.org/en-US/docs/Web/CSS/Media_Queries/Using_media_queries
- Адаптивная раскладка «по-взрослому» — Grid-шаблон с `auto-fit`/`minmax()`: без медиазапросов.
  https://developer.mozilla.org/en-US/docs/Web/CSS/grid-template-columns

## Пошаговая инструкция

1. В `index.html` подключите стили: `<link rel="stylesheet" href="css/style.css">`.
2. Откройте `css/style.css` (рабочая копия). Выберите тему: фон, основной текст, акцентный
   цвет, цвет «карточек», радиус скругления, размер отступа. Пропишите значения в `:root`.
3. Настройте `body`: фон `var(--color-bg)`, цвет `var(--color-text)`, шрифт `system-ui`,
   межстрочный интервал `1.6`.
4. Раскладка страницы:
   - `main` + `aside` оберните в контейнер (см. `index.html` — `<div class="layout">`);
   - задайте `display: grid; grid-template-columns: 1fr 280px; gap: var(--gap);`.
5. Оформите шапку/меню: `header` — панель (Flexbox, горизонтальные пункты), ссылки `nav a` —
   без подчёркиваний, с отступами; активный/над `:hover` — акцентным цветом.
6. Карточки записей: `article` — белый фон `var(--color-card)`, радиус `--radius`,
   мягкая тень, внутренний отступ; заголовки ссылками-акцентом; у `time` — серый мелкий шрифт.
7. Сайдбар: ссылки категорий — списком-«палочками», паддинги, разделители.
8. Кнопка «Читать далее»/ссылки — акцент, `:hover` меняет на инвертированный.
9. Адаптив:
   ```css
   @media (max-width: 768px) {
     .layout { grid-template-columns: 1fr; }   /* сайдбар под контентом */
   }
   @media (max-width: 480px) {
     nav { flex-direction: column; }           /* меню вертикально */
   }
   ```
10. Проверьте в браузере: DevTools → режим устройства (иконка телефона) → ширины 375 и 1280.
    Убедитесь, что нет горизонтальной прокрутки (не вылезает ничего за контейнер).

## Самопроверка

- Зачем цитировать `currentColor`/`var()` вместо «зашитых» цветов? (Чтобы менять тему в одном месте.)
- Чем Flexbox отличается от Grid? Когда какой? (Flex — в ряд/колонку, Grid — по строкам и столбцам.)
- Почему `box-sizing: border-box` почти всегда ставят глобально? (padding не раздувает размер элемента.)
- Что произойдёт на телефоне, если убрать медиазапросы? (Раскладка «сожмётся» и станет нечитаемой.)

## Критерий «зачтено»

- Тема задана CSS-переменными.
- Раскладка контент+сайдбар — Grid/Flexbox.
- На 375 px: сайдбар под контентом, меню вертикальное, нет горизонтальной прокрутки.
- На 1280 px: аккуратная трёхвременная сетка/контент+280px-сайдбар.
