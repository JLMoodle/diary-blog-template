## Ответы на вопросы самопроверки

1. `const` запрещает повторное присваивание, `let` разрешает. По умолчанию используется `const`, а `let` — только для изменяемых значений.
2. `sortPostsByDate` возвращает копию, чтобы не менять исходный массив `posts` и не нарушать работу фильтра.
3. `filter` без совпадений возвращает пустой массив; `renderPosts` обрабатывает его сообщением «Записей нет.».
4. `==` приводит типы, `===` сравнивает без приведения. В курсе используется `===`, чтобы избежать неожиданных совпадений.
5. Именованная функция поднимается (hoisting) и удобна для переиспользования; стрелочная функция короче и не имеет собственного `this`.
