Затем открыть `http://localhost:8000/`. Через `file://` запрос `fetch` работать не будет — это ограничение браузера.

## Ответы на вопросы самопроверки

1. `fetch` не выбрасывает исключение при ответе 404: промис переходит в состояние fulfilled. Поэтому нужно самостоятельно проверять `response.ok` и выбрасывать ошибку через `throw`.
2. `res.json()` разбирает тело ответа как JSON и возвращает объект/массив; `res.text()` возвращает обычную строку. JSON нужен для структурированных данных, текст — для HTML, CSV или отладочного вывода.
3. `throw` внутри `if (!response.ok)` переводит выполнение в `catch`, чтобы пользователь увидел сообщение об ошибке, а не пустой список.
4. Обычная функция не умеет приостанавливаться и ждать завершения промиса; `async/await` позволяет дождаться ответа и только потом продолжить выполнение.
