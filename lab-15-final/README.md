# Лабораторная работа №15 (финал) — Сборка, решение, документация

**Тема:** релиз проекта. **Цель:** собрать блог «по-человечески»: починить то, что
осталось незакрытым из лаб 1–14, написать нормальный README, сделать релиз-тег `v1.0`
и подготовить защиту.

## Чек-лист (финал)

- [ ] Проект запускается «с нуля» по README за 3 шага: `composer dump`/`php -S`,
      импорт схемы, `.env` (см. лабы 7–12).
- [ ] Главная: JOIN+пагинация (лаба 12), поиск через FULLTEXT, фильтры и «свежие
      комментарии» работают вместе.
- [ ] CRUD (лаба 11) + авторизация (лаба 14): гость видит записи, но не может
      добавлять/редактировать/удалять без входа.
- [ ] Безопасность (лаба 14) не «отвалилась»: быстрый прогон чек-листа лабы 14.
- [ ] README проекта: название, описание, схема БД, скриншот, раздел «Безопасность»
      и «Оптимизация» (до/после), инструкция запуска, чек-лист выполнения 15 лаб.
- [ ] В корне репозитория — НЕ только папки лаб: ваша «собранная» копия проекта
      (index.php, includes/, posts/, js/, css/, database/, .env.example, README.md).
- [ ] Тег релиза: `v1.0` (и push `--tags`).

## Ход работы

1. Скопируйте свои лучшие наработки из lab-01…14 в корень репозитория (как договаривались
   в лабе 1): главная `index.php`, `includes/`, `posts/`, `js/`, `css/`, `database/schema.sql`.
2. Прогоните чек-лист лаб 7–14 по очереди; то, что сломано, — переделайте (заново).
3. Напишите финальный `README.md` (можно взять за основу README этой лабы + README лабы 7).
4. Снимите скриншоты: главная, запись, добавление, вход — положите в `docs/` и воткните
   в README (Markdown: `![Главная](docs/main.png)`).
5. Проверьте, что `.env` не в git, а в README описан шаблон `.env.example`.
6. Релиз:
   ```bash
   cd diary-blog
   git add .
   git commit -m "[lab-15] Финальная сборка и релиз v1.0"
   git tag v1.0
   git push && git push --tags
   ```

## Самопроверка

- Опишите в двух абзацах: что вы умеете теперь и что из этого пригодится в проекте на пары.
- Что оказалось самым сложным в курсе и как вы это преодолели?
- Какая из 15 лаб «самая ценная» лично для вас и почему?

## Критерий «зачтено»

- Блог живёт на `https://github.com/<ваш логин>/diary-blog`; тег `v1.0` существует;
  на `v1.0` открывается рабочая главная с записями из БД; README полный и честный.

## Как отправить

```bash
git tag v1.0 && git push && git push --tags
```
Сдаёте: `v1.0` + `https://github.com/<ваш логин>/diary-blog/tree/v1.0`.
Поздравляю — это финал курса. 🎓
