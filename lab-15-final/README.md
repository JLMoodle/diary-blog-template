## Как работать в этой лабе (общий репозиторий группы)

Это **финальная** лаба. Вы работаете в подпапке `lab-15-final/<Фамилия>/` по протоколу
общей группы (см. lab-01): итоговый блог собирается именно туда, а личный отчёт — в README
этой подпапки.

1. Перед началом работы забрать чужие правки: `git pull --rebase`.
2. Работаете только в `lab-15-final/<Фамилия>/`; чужие подпапки и скелеты не трогайте.
3. Итоговая сдача курса = собранный блог в вашей подпапке **+ личный отчёт** в её README;
   деплой на хостинг — по желанию (ссылка на работающий сайт в отчёте).
4. Тег `v1.2` в шаблоне — актуальная версия курса: его обновляет преподаватель, студенты
   личные релиз-теги в общем репо не ставят.
