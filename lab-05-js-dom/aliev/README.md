## Что реализовано

- [x] Карточки записей создаются средствами DOM: `createElement`, `textContent`, `append`, без `innerHTML` для пользовательских данных.
- [x] Добавлена форма «Новая запись» с полями «Заголовок», «Категория», «Текст записи».
- [x] Валидация: заголовок не короче 3 символов, текст — не короче 20, категория обязательна.

- [x] Успешная запись добавляется в начало списка и сохраняется в `localStorage` под ключом `diary-blog-user-posts`.
- [x] При загрузке сохранённые записи объединяются с базовым массивом `posts`.
- [x] События подключаются через `addEventListener`, без inline-атрибутов.
- [x] Фильтр по категориям работает и для базовых, и для добавленных записей.

## Запуск

Открыть `index.html` в браузере. Для проверки сохранения добавить запись, обновить страницу — запись должна остаться.

## Ответы на вопросы самопроверки

1. `textContent` вставляет строку как текст. Если ввести `<b>жирный</b>` через `innerHTML`, браузер создаст HTML-элемент, а через `textContent` эти символы останутся текстом. Это защищает от XSS.
2. `e.preventDefault()` отменяет стандартную отправку формы и перезагрузку страницы, чтобы обработать данные в JavaScript.
3. `localStorage` хранит только строки. `JSON.stringify` превращает массив объектов в строку, а `JSON.parse` восстанавливает структуру.
4. Самой свежей считается запись с более поздней датой; добавленная запись получает текущую дату и после сортировки оказывается сверху.
